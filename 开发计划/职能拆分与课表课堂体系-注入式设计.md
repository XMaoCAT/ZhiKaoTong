### 1.3 两条核心数据流（注入后的目标时序）

**审批流（以教师加课为例）**：
```
教师端(mod-courses 点空格) → POST /api/workflow/requests {type:'add-lesson', payload}
  → workflow.js: validator 预检(本人授课班/时段格式/冲突) → INSERT workflow_requests(pending)
  → publishToRole('教务处', 'workflow:request-new', request)
  → 教务处端(mod-lesson-review) SSE 收到 → eventBus('sse:workflow-request-new') → 审批弹窗
  → POST /api/workflow/requests/:id/review {action:'approve'}
  → workflow.js: TYPE_HANDLERS['add-lesson'].executor 事务(冲突复检→INSERT timetable_lessons)
                + INSERT notifications(audience=class) + publishToClass(classId,'timetable:lesson-added')
  → 学生端(mod-courses) SSE 收到 → 弹"新课通知"+课表重渲染；教师端收到 request-reviewed 结果窗
```

**课堂流（请假联动为核心接缝）**：
```
教师端(mod-classroom 发起) → POST /api/classroom/sessions {classId, lessonId?}
  → classroom.js: 事务内 ①INSERT lesson_sessions(open)
                  ②预置请假：查 leaves WHERE student_id∈本班 AND status∈('approved','completed')
                    AND 时段与 session 相交 → INSERT sign_records(status='leave')
                  ③publishToClass(classId,'classroom:session-opened')
  → 学生端(mod-courses) 弹签到卡（请假学生显示"请假"标签且无签到按钮）
  → 学生提交 → POST /sessions/:id/sign {code?} → INSERT sign_records(signed)
  → 教师随人/加减分/旷课 → classroom_events + violation_records(同事务扣 students.score)
  → 教师结束 → status=ended + publishToRole('导员')+publishToRole('教务处','classroom:session-ended')
```

### 3.3 泛化申请/通知两表（替代一期专属表设计）

```sql
CREATE TABLE IF NOT EXISTS workflow_requests (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  type TEXT NOT NULL CHECK (type IN
    ('class-create','class-edit','class-dissolve',      -- 一期：教务处→学生处
     'add-lesson','teacher-leave','absence-cancel',     -- 二期：教师→教务处
     'record-modify')),                                 -- 二期：教务处→教师（确认制）
  title TEXT NOT NULL,
  payload TEXT NOT NULL,              -- JSON，按 type 见 §5.3
  status TEXT NOT NULL DEFAULT 'pending'
        CHECK (status IN ('pending','approved','rejected','withdrawn')),
  requested_by TEXT NOT NULL,         -- 账号名（教师01 / 教务处）
  requested_role TEXT NOT NULL,       -- '教务处' | '教师'
  audience TEXT NOT NULL,             -- 审批方角色：'学生处' | '教务处' | '教师'
  reviewed_by TEXT, reject_reason TEXT, result TEXT,
  created_at TEXT NOT NULL DEFAULT (datetime('now','localtime')),
  reviewed_at TEXT
);
CREATE INDEX IF NOT EXISTS idx_wf_status ON workflow_requests (status, created_at);
CREATE INDEX IF NOT EXISTS idx_wf_audience ON workflow_requests (audience, status);

CREATE TABLE IF NOT EXISTS notifications (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  audience_type TEXT NOT NULL CHECK (audience_type IN ('role','class','teacher')),
  audience_key TEXT NOT NULL,         -- '教务处' | classId | teacher_name
  kind TEXT NOT NULL,                 -- §13 六种
  request_id INTEGER, title TEXT NOT NULL, detail TEXT,
  read_at TEXT,                       -- NULL=未读（离线补弹依据）
  created_at TEXT NOT NULL DEFAULT (datetime('now','localtime'))
);
CREATE INDEX IF NOT EXISTS idx_ntf_audience ON notifications (audience_type, audience_key, read_at);
```

## 8. 注入点 G：课堂管理（classroom API + mod-classroom + 三方视图）

### 8.1 `src/api/classroom.js` 端点群（写限教师本人 session，教师/IT；读教师本人/教务/IT）

- `POST /api/classroom/sessions {classId, lessonId?, courseName?, startTime?, endTime?, signMode('code'|'click'), signCode?}` → 事务：INSERT session(open) + **预置请假**（`SELECT student_id FROM leaves WHERE student_id IN (本班) AND status IN ('approved','completed') AND date_from<=date AND date_to>=date AND (跨日或时段相交)` → INSERT sign_records(status='leave', method='leave-auto')）+ `publishToClass(classId,'classroom:session-opened',sessionBrief)`。口令：code 模式未传则随机 4 位数字生成。
- `POST /sessions/:id/sign {code?}` → 学生（校验 session open + 本班 + code 匹配 400）→ INSERT/UPDATE sign_records(signed, method)。
- `GET /sessions/:id` → 详情（三类名单+事件流+实时计数）——教师面板轮询 3s 或 SSE 增量（**取舍：轮询 3s 足够，演示规模下零压力，SSE 反而多一套状态同步**——设计取轮询，SSE 仅负责"出现/结束"边界事件）。
- `POST /sessions/:id/end` → status=ended + INSERT classroom_events? 否（end 本身由 session 行承载）+ `publishToRole('导员','classroom:session-ended')` + `publishToRole('教务处',...)`。
- `POST /sessions/:id/proxy-sign {studentId}`（教师代签）→ UPDATE sign_records(signed_by_teacher, proxy)。
- `POST /sessions/:id/score {studentId, delta∈[1,2,-1,-2], note?}` → INSERT classroom_events(score)。
- `POST /sessions/:id/pick {studentIds[]}` → INSERT classroom_events(pick) 批量。
- `POST /sessions/:id/absence {studentId}` → **事务**：INSERT violation_records(旷课,auto,-5) + `UPDATE students SET score=score-5` + UPDATE sign_records(absent) + INSERT classroom_events(absence)。
- `DELETE /sessions/:id/absence/:studentId` → open 期：事务反向（UPDATE violation cancelled=1 + 还分 + sign_records 回置）；**ended 期返回 409 + 引导文案**"课后撤销需提交申请至教务处"。
- `GET /sessions?teacher=&date=&all=` → 教师/教务历史列表。

### 8.2 新模块 `mod-classroom`（教师，manifest groups=[教师,IT管理员]）
