## 2. 数据层（3 张新表 + JSON 单源）

```sql
CREATE TABLE IF NOT EXISTS surveys (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  kind TEXT NOT NULL CHECK (kind IN ('questionnaire','vote')),
  title TEXT NOT NULL,
  description TEXT DEFAULT '',
  anonymous INTEGER NOT NULL DEFAULT 0,          -- 1=匿名（明细永不输出；仅分布+已填名单）
  status TEXT NOT NULL DEFAULT 'draft' CHECK (status IN ('draft','published','closed')),
  questions TEXT NOT NULL DEFAULT '[]',          -- 问卷题目：[{id,type(single|multi|text|date|number),title,required,options[]}]
  vote_config TEXT,                              -- 投票配置：{options:[{id,label}],votesPerPerson,
                                                 --   allowRepeatOption,allowRevote,resultVisibility('after-vote'|'owner')}
  audience TEXT NOT NULL DEFAULT 'students' CHECK (audience IN ('students','teachers','all')),
  target_class_ids TEXT,                         -- JSON 数组；NULL/[]=全部学生（仅 audience 含 students 生效）
  target_teacher_names TEXT,                     -- JSON 数组；NULL/[]=全部教师（仅 audience 含 teachers 生效）
  visibility TEXT NOT NULL DEFAULT '{}',         -- {statsViewers:[角色],detailViewers:[角色]}；发起人+IT 恒可见统计
  deadline TEXT,                                 -- 'YYYY-MM-DDTHH:MM' 或 NULL；过期禁填禁投
  created_by TEXT NOT NULL, created_role TEXT NOT NULL,
  created_at TEXT NOT NULL DEFAULT (datetime('now','localtime')),
  published_at TEXT, closed_at TEXT
);
CREATE INDEX IF NOT EXISTS idx_sv_status ON surveys (status, created_at);

CREATE TABLE IF NOT EXISTS survey_responses (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  survey_id INTEGER NOT NULL,
  respondent_type TEXT NOT NULL CHECK (respondent_type IN ('student','teacher')),
  respondent_id TEXT NOT NULL,                   -- 学号 / 教师账号名
  answers TEXT NOT NULL DEFAULT '[]',            -- [{questionId,value}]（value：单选=选项文本；多选=文本数组；其余=字符串）
  created_at TEXT NOT NULL DEFAULT (datetime('now','localtime')),
  UNIQUE (survey_id, respondent_type, respondent_id)   -- 一卷一填不可改
);
CREATE INDEX IF NOT EXISTS idx_sr_survey ON survey_responses (survey_id);

CREATE TABLE IF NOT EXISTS survey_ballots (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  survey_id INTEGER NOT NULL,
  respondent_type TEXT NOT NULL CHECK (respondent_type IN ('student','teacher')),
  respondent_id TEXT NOT NULL,
  option_id TEXT NOT NULL,
  vote_count INTEGER NOT NULL DEFAULT 1 CHECK (vote_count >= 1),  -- 同选项累计票数（allowRepeatOption 时可>1）
  created_at TEXT NOT NULL DEFAULT (datetime('now','localtime')),
  updated_at TEXT,
  UNIQUE (survey_id, respondent_type, respondent_id, option_id)
);
CREATE INDEX IF NOT EXISTS idx_sb_survey ON survey_ballots (survey_id);
```

**投票提交模型**：`{ choices: [{optionId, count}] }`，服务端事务内校验——
`SUM(count) ≤ votesPerPerson`；`!allowRepeatOption` 时每项 `count===1`（选项天然去重）；`!allowRevote && 已投` → 400；落库=**先删本人旧行再插新行**（整体覆盖式改票）。匿名卷 ballots/respondent_id 仍在库（防重+已投判定），输出层脱敏（§0 Q1）。

## 3. API 设计（src/api/surveys.js，10 端点 + 守卫矩阵）

| 方法 | 路径 | 权限 | 说明 |
| :--- | :--- | :--- | :--- |
| POST | `/api/surveys` | CREATE_ROLES（学生处/教务处/IT 任意；导员强制限绑定班且 audience=students） | 创建草稿（validator：题目/选项/开关/受众/截止全量校验） |
| GET | `/api/surveys` | 六角色登录 | 按角色分支：学生/教师=可填列表（含已填/已投标记与我的选择）；导员=绑定班可见的已发布+我创建的；学生处/教务处/IT=全部 |
| GET | `/api/surveys/:id` | 受众或发起人或可见统计角色 | 详情（含 questions/voteConfig/我的作答或选票/截止状态） |
| POST | `/api/surveys/:id/publish` | 发起人/IT（draft） | 发布→通知+SSE 三级频道定向 |
| POST | `/api/surveys/:id/close` | 发起人/IT（published） | 关闭→通知受众 |
| POST | `/api/surveys/:id/submit` | 受众（published+未填+未过期） | 问卷作答（必填校验；选项值白名单校验） |
| POST | `/api/surveys/:id/vote` | 受众（published+未过期） | 投票/改票（§2 规则引擎） |
| POST | `/api/surveys/:id/remind` | 发起人/导员（限绑定班未填者）/IT | 催填：仅向未填/未投者发通知+SSE |
| GET | `/api/surveys/:id/stats` | statsViewers/发起人/IT（导员自动收窄绑定班） | 填写率+未填名单+题目分布（问卷）/票数统计（投票，按 resultVisibility 决定投票人能否看）+实名明细（实名卷且 detailViewers） |
| DELETE | `/api/surveys/:id` | 发起人/IT | 危险操作：连带删 responses/ballots |

**守卫常量**（文件内，与 leaves.js/academic.js 同风格）：
`CREATE_ROLES=['学生处','教务处','IT管理员','导员']`（导员 audience/target 收窄）；`SUBMIT` 走受众判定函数 `isAudience(row, req)`；`stats` 走 `canViewStats(row, req)`（发起人本人/IT/statsViewers 含角色；导员叠加绑定班数据过滤）。

**通知构造**（复用 workflow.js 模式，本文件内实现 addNotification+publishForAudience 同款）：
- 发布：students 全部→`role:学生`；定向班→逐 `class:<id>`；teachers 全部→`role:教师`；定向→逐 `teacher:<名>`；all→双 role
- 关闭/催填同频道（催填仅未填者——学生按班算未填集合后逐频道或 role+audience_key='class' 组合，**催填通知落库 audience 仅记 role/class 维度，发送用频道定向**）
- kind：`survey-published` / `survey-closed` / `survey-reminded`（进受众「消息」tab 自动复用 B1）

## 8. 测试矩阵（验收基线）

**API（S4，冒烟脚本断言状态码）**
- 权限：学生创建 403 / 导员创建非绑定班 400 / 教师提交非受众 403 / 学生看他人卷统计 403 / 导员看非 statsViewers 卷 403 / 匿名卷任何身份要明细 403 / resultVisibility=owner 时投票人看票数 403
