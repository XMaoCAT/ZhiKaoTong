## 1. 题型体系（九类 · questions schema v2）

### 1.1 题型清单与数据结构

```js
questions: [
  {
    id: 'q1',                        // 题号（设计器按序生成 q1..qN）
    type: 'single',                  // ①题型枚举（下表九类）
    title: '假期是否离校？',
    required: true,
    options: ['离校', '留校'],       // 选择类选项（single/multi/dropdown/sort）
    otherOption: true,               // ⑤「其他」补充填空开关（single/multi/dropdown）
    minSelect: 1, maxSelect: 3,      // ⑦多选上下限（仅 multi；不配=不限）
    format: 'number',                // ①填空格式（仅 text）：any|number|date|phone|email
    scale: { min: 1, max: 5, lowLabel: '很不满意', highLabel: '很满意', skin: 'radio' },  // ⑥量表（仅 scale；skin: radio|star|nps）
    rows: [{ id: 'r1', label: '教学质量' }, { id: 'r2', label: '食堂' }],   // 矩阵行（子题）
    cols: [{ id: 'c1', label: '满意' }, { id: 'c2', label: '一般' }, { id: 'c3', label: '不满意' }], // 矩阵列（matrix-single 模式）
    matrixMode: 'single' | 'scale',  // 矩阵模式：单选列 | 量表（配 scale 复用⑥）
    visibleWhen: { op: 'and', rules: [{ questionId: 'q1', optionValues: ['离校'] }] },  // ②④显示条件（§2）
  }
]
```

### 1.2 题型九类 · 作答值（value）存储契约（前后端统计/CSV 统一）

| type | 题名 | value 形态 | 校验规则 |
| :--- | :--- | :--- | :--- |
| `single` | 单选题 | `'选项文本'`；选其他=`{ option: '__other__', otherText: '说明' }` | 值 ∈ options 或其他对象 |
| `multi` | 多选题 | `['A','B']`（数组；含其他时元素可为其他对象） | 每项 ∈ options；去重；满足 min/maxSelect |
| `dropdown` | 下拉题 | 同 single | 同 single |
| `sort` | 排序题 | `['C','A','B']`（按序全量数组） | 必须为 options 的完整排列 |
| `text` | 填空题 | `'字符串'`（format=number 时存数字字符串） | 按 format 正则校验 |
| `textarea` | 多行文本 | `'字符串'` | 长度 ≤500 |
| `scale` | 量表题 | `4`（数字，∈ [min,max]） | 整数且在档位内 |
| `matrix` | 矩阵题 | `{ r1: '满意', r2: 2 }`（行 id → 列文本或分值） | 键=全部 rows（required 时）；值合法 |
| `file` | 附件题 | `['dataURL1', ...]`（≤3 个） | 前缀 data:、大小前端压缩/拦截 |

> 是非题不独立建模=设计器「单选」提供 *一键生成 是/否 选项* 快捷按钮；NPS/星级=scale 的 skin 变体（0-10 无标签 / 星星渲染），数据模型同一。

### 1.3 统计规则（按题型适配，stats.distribution）

| type | 统计呈现 |
| :--- | :--- |
| single/dropdown | 选项计数条形 + 其他文本列表 |
| multi | 选项计数条形（人次）+ 其他文本列表 |
| sort | 各选项平均位次 + 被排第一的分布 |
| text/textarea | 文本值列表（实名明细已有；匿名聚合为计数） |
| scale | **均值** + 各档位计数条形 |
| matrix | 每行（子题）独立分布/均值条形 |
| file | 附件总个数；（实名卷明细可展开查看，匿名仅计数） |

CSV 导出同步适配九类（明细行按题输出 value 的规范化字符串：其他→`其他：说明`；矩阵→`行:值;` 连接）。

## 2. 显示逻辑引擎（visibleWhen · 核心新增）

### 2.1 数据结构（多条件且/或）

```js
visibleWhen: {
  op: 'and' | 'or',                                    // 条件间组合（单条件时 op 可省）
  rules: [
    { questionId: 'q1', optionValues: ['离校'] },      // 一条规则=来源题答案包含任一勾选选项
    { questionId: 'q3', optionValues: ['A', 'B'] },
  ],
}
```

- **来源题限定**：仅允许本题**之前**的 `single / multi / dropdown`（有选项的题型）；规则内 optionValues 须 ∈ 来源题 options（含 `__other__` 也可触发——选了"其他"即命中）。
- **无 visibleWhen = 始终显示**（现状兼容）。

### 2.2 判定算法（服务端 submit 校验器与前端填写端共用同一规则）

```
isVisible(q, answers):
  if (!q.visibleWhen || !q.visibleWhen.rules.length) return true
  每 rule：取来源题 src 的答案 ans
    src 为 single/dropdown：ans.option/字符串 ∈ rule.optionValues（含 __other__ 时 ans 为其他对象即命中）
    src 为 multi：ans 数组与 optionValues 有交集
    来源题不可见或未答 → 该规则判 false（级联隐藏；and/or 自然短路）
  按 op 汇总（and=全部真；or=任一真）
```

- **级联**：来源题自身被隐藏→其答案视为无→规则 false→依赖题隐藏（多层链路递归求解，题目按序求值一次即可：q 依赖 q'（q'<q），先算 q'）。
- **隐藏题**：不校验必填；submit 时**服务端强制剔除**其答案（防前端绕过；answers 中出现不可见题→直接丢弃该题作答）。
- **环路检测（创建时 400）**：来源题必须 id 序小于当前题（设计器只允许选之前的题，天然无环；服务端仍复检 questionId 索引 < 当前索引，否则 400）。

### 2.3 交互设计

**创建端（设计器每题块）**：
- 「显示条件」折叠区（默认收起显示"始终显示"）→ 展开后：条件行列表（每行=来源题下拉[仅之前的单选/多选/下拉] + 触发选项 chips 多选）+ 行间 且/或 切换 + 增删条件行。
- 实时预览提示行：`仅当 Q1 选「离校」且 Q2 选「A/B」时显示本题`。

**填写端（PC 与移动端 in-host 同逻辑）**：
- 每次作答变更→重算全卷可见性→条件题显/隐（CSS 过渡；隐藏题的已填值保留在内存，恢复显示不丢，提交时统一按可见性过滤）。
- 隐藏题渲染 `hidden`（配套 [hidden] 规则，踩坑 #04 纪律）。
- 已填回显视图同样按可见性快照渲染（以提交时的实际可见集为准）。

## 5. 测试矩阵要点（S19 冒烟核心用例）

- **逻辑**：单条件显示/隐藏；and（两条件全真才显）；or（任一真即显）；级联（来源题隐藏→依赖题隐藏）；选「其他」触发条件；环路（visibleWhen 引用之后的题）→400；来源题选项值非法→400
- **隐藏剔除**：前端正常提交（隐藏题无值）；伪造 answers 含隐藏题答案→库内无该题；隐藏必填题不拦截提交
- **九类**：single 其他对象；multi 上下限（少于 min 400/多于 max 400/恰好在 200）；sort 非全排列 400；text 五种 format（错格式 400）；scale 越档 400/小数 400；matrix 缺行（required）400；file 超 3 个 400；textarea 超长 400
- **统计**：scale 均值=构造值；矩阵行分布正确；排序平均位次正确；其他文本聚合正确
- **兼容**：旧无 visibleWhen/otherOption 题型行为不变（现有三题型映射：text→text、date→text.format=date、number→text.format=number——**已发布历史卷无生产数据（S13 已清），无迁移负担**）

## 6. 不做边界（本轮）

跳转逻辑（选 A 跳到第 X 题）；题目/选项引用替换（标题引用上题答案）；选项随机排序；条件引用填空值（如"分数>60 才显示"——条件仅支持选项命中）；矩阵多选/矩阵填空模式（仅矩阵单选+矩阵量表）；附件真实文件存储（维持 dataURL，§17）；逻辑的嵌套条件组（仅一层 and/or 扁平组合）。
